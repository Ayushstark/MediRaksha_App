# MediRaksha Frontend

Expo React Native frontend for the MediRaksha healthcare app.

## Local Setup

```bash
npm install
copy .env.example .env
npm start
```

Set `EXPO_PUBLIC_BACKEND_URL` in `.env` to the backend API URL, usually:

```env
EXPO_PUBLIC_BACKEND_URL=http://localhost:3000/api
```

For full project setup, backend configuration, persistence notes, and troubleshooting, see the root [README.md](../README.md).
